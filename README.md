# 桌面图标开关 (Desktop Icons Toggle)

一键显示 / 隐藏 Windows 11 全部桌面图标的小工具。

**创作者：Daniel + deepseek-v41-flash** · 邮箱：1509890480@qq.com

---

## 简介

Windows 11 从 23H2 起，系统自带的"显示桌面图标"开关在某些环境下会失效
（注册表 `HideIcons` 与相关系统接口均不再生效）。

本工具绕开这个失效的开关，让你随时用一个热键隐藏或恢复全部桌面图标，
适合：

- 开会 / 演示时快速清空桌面
- 录屏、截图前想要一个干净桌面
- 不想让别人看到桌面上的文件

---

## 功能

| 功能 | 说明 |
|---|---|
| 显示 / 隐藏桌面图标 | 热键 `Ctrl + Alt + I`，可反复切换 |
| 退出程序 | 热键 `Ctrl + Alt + Q` |
| 托盘图标 | 双击切换；右键菜单：切换 / 开机自启 / 关于 / 退出 |
| 开机自动启动 | 托盘右键勾选即可，随时可关 |
| 单文件绿色版 | 14 KB，无需安装、无需管理员权限 |

**不需要切换输入法**，从任何窗口按热键都有效。

## 使用方法

> 📖 更详细的图文步骤、常见问题与技巧，见 **[USAGE.md（使用说明）](USAGE.md)**

1. 双击 `DesktopIconsToggle.exe`（通知区域会出现一个小图标）
2. 按 `Ctrl + Alt + I` 显示 / 隐藏桌面图标
3. 想退出就按 `Ctrl + Alt + Q`

### 开机自动启动

- 图形方式：托盘图标右键 → 勾选「开机自动启动」
- 命令行方式：
  ```
  DesktopIconsToggle.exe --install      开启
  DesktopIconsToggle.exe --uninstall    关闭
  ```

### 命令行参数

```
DesktopIconsToggle.exe                启动托盘程序（正常使用）
DesktopIconsToggle.exe --install      开启开机自启
DesktopIconsToggle.exe --uninstall    关闭开机自启
DesktopIconsToggle.exe --toggle       只执行一次切换，不驻留
```

### 配置文件

`DesktopIconsToggle.ini` —— 内容为一个数字，表示内部按键间隔（毫秒），
默认 `100`，有效范围 `10 ~ 5000`。修改后需重启程序。

## 常见问题

**Q：按热键没反应？**
1. 确认程序正在运行（通知区域有图标）
2. 确认 `Ctrl+Alt+I` 没有被其他软件占用
3. 检查是否被杀毒软件拦截

**Q：桌面图标被隐藏了，怎么恢复？**
1. 再按一次 `Ctrl + Alt + I`
2. 托盘图标右键 → 显示 / 隐藏桌面图标
3. 兜底方案：右键桌面 → 查看 → 显示桌面图标

**Q：它会修改我的系统吗？**
不会。它不写注册表（除非你自己开启「开机自启」，那也只是一条启动项），
不修改系统设置，不重启资源管理器。所有操作都等同于你手动按快捷键
并点击菜单，效果完全一致、随时可逆。

**Q：为什么需要开机自启？关掉有影响吗？**
关掉只是下次开机要手动启动程序，功能本身不受影响。

**Q：支持 Windows 10 吗？**
未测试。Windows 10 及 Windows 11 较早版本系统自带的开关是可用的，
不需要本工具。
